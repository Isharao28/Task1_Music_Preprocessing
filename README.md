# Task 1 - Music Dataset Preprocessing

## Objective
To clean and preprocess Spotify dataset for machine learning.

## Tools Used
- Google Colab
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Steps Performed
1. Imported dataset
2. Checked missing values
3. Handled null values
4. Encoded categorical features
5. Standardized numerical columns
6. Visualized outliers using boxplot
7. Removed outliers using IQR
8. Saved cleaned dataset
   
## Dataset
Spotify Tracks Dataset from Kaggle
